# Conecta Jovem — versão 2

Site estático para GitHub Pages, com uma página própria para cada área.

Arquivos:
- index.html
- style.css
- estudos.html
- carreira.html
- autoconhecimento.html
- esporte.html
- cultura.html
- apoio.html

Para publicar: GitHub → repositório → Settings → Pages → Deploy from a branch → main → / (root).

Os links de oportunidades levam a páginas externas quando disponíveis.

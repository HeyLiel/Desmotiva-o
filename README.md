# Conecta Jovem

Site institucional/interativo criado a partir da apresentação do projeto **Conecta Jovem — Jovens Cada Vez Mais Desmotivados**.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `conecta-jovem`.
2. Envie estes três arquivos para a raiz do repositório:
   - `index.html`
   - `style.css`
   - `script.js`
3. No GitHub, entre em **Settings → Pages**.
4. Em **Build and deployment**, selecione:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Salve e aguarde a publicação.

O site não usa banco de dados nem servidor. Ele funciona como site estático e pode ser hospedado gratuitamente no GitHub Pages.

## Arquivos

- `index.html` — estrutura e conteúdo
- `style.css` — visual/responsividade
- `script.js` — interações dos cards e menu
